King James Version (1769 standard text, public domain) - one file per book, 01.json (Genesis) ... 66.json (Revelation).
Each file is an array of chapters; each chapter is an array of verse strings (verse 1 = index 0).
null = a verse whose wording could not be double-checked across sources; the site then shows the reference only.
Built by tools/lessons/build_kjv_full.py from the open-bibles eng-kjv OSIS text (the source used by bible-api.com),
cross-checked verse-by-verse against Project Gutenberg #10 and getBible; used only for the video-lesson verse boxes.
